# TabEcho Usage & Shortcuts Guide

## Core Concepts

- **Source Tab**: The single browser tab where you perform interactions.
- **Target Tabs**: One or more browser tabs (spread across any number of Chrome windows) that replicate Source actions in real time.

## Shortcut Reference

### Page-Level Shortcuts (Source Tab Focused)

| Action | Default Shortcut | Scope |
|--------|------------------|-------|
| Pause Sync | `Escape` | Source Webpage |
| Resume Sync | `F8` | Source Webpage |
| Toggle Pause/Resume | `F9` | Source Webpage |
| Stop Session | `F10` | Source Webpage |
| Emergency Stop | `Ctrl + Shift + F12` | Source Webpage |

### Browser-Level Extension Commands (Global)

| Action | Default Shortcut | Scope |
|--------|------------------|-------|
| Toggle Pause/Resume | `Ctrl + Shift + P` | Chrome Browser |
| Resume Sync | `Ctrl + Shift + R` | Chrome Browser |
| Stop Session | `Ctrl + Shift + S` | Chrome Browser |
| Emergency Stop | `Ctrl + Shift + X` | Chrome Browser |

*Customize browser shortcuts via `chrome://extensions/shortcuts`.*
